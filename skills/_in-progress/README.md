# In progress

Drafts that are not ready to ship. **Excluded from the deploy and from every index**, exactly like
`_deprecated/`, so an unfinished skill can live in the repo without competing for a trigger.

Graduating a skill: move it up to `skills/`, run the authoring audit in `docs/SKILL-STANDARD.md`,
regenerate the indexes, and decide the invocation axis. Add it to `claude-code/skills-core.txt`
only if it clears the admission criterion written at the top of that file.
