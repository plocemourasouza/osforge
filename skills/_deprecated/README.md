# Deprecated

Skills kept for reference and no longer in use. **Excluded from the deploy, from the core
allowlist, from `SKILLS.md`, from `INDICE-SKILLS.json` and from the triggering suite** — a skill in
here does not exist at runtime.

Deleting is the alternative, and usually the wrong one: the reason a skill was retired is often
recoverable material. Retire first, delete when nobody has reached for it in months.
